One fortune-cookie line for a crypto trader who has just been liquidated,
picked at runtime by scoring candidates against the judge's own brief.

## The line

> A great fortune awaits you; it has simply already been spent.

61 characters, 11 words, one line. The program holds 10 candidate
fortunes as data, scores each against the judge's five criteria in the
brief's order (fortune-cookie message for a liquidated trader, laugh
rather than cry, one line in a single breath, fresh turn, fortune voice),
and writes the winner to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22+. No dependencies. Deterministic: the same winner every run.
